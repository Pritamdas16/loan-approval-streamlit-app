# 🏦 Loan Approval Prediction using Machine Learning

## 📌 Overview
This project predicts **loan approval status** using customer financial and demographic data.  
Multiple machine learning models are trained and compared to analyze credit risk and approval patterns.

The project demonstrates a complete **machine learning workflow** from data preprocessing to model evaluation.

---

## 🤖 Models Used
The following classification models are implemented:

- Logistic Regression  
- K-Nearest Neighbors (KNN)  
- Naive Bayes  

---

## 🔁 Workflow
The project follows these steps:

- Data preprocessing and cleaning  
- Feature engineering  
- Encoding categorical variables  
- Feature scaling  
- Model training  
- Model evaluation and comparison
